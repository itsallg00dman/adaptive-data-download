# 神经影像项目案例

这套工具来自一次公开神经影像数据下载。原流程先按官方数据源生成文件清单，检查目标硬盘和可用容量，再用 AWS CLI 或 aria2 传输。完成后按清单逐文件核对长度及校验记录，保留原始目录、元数据与说明，另外抽样读回哈希、压缩包结构和影像头。

| 数据集 | 公开 S3 目录 | 当时用法 | 文件与容量 |
| --- | --- | --- | ---: |
| FCP1000 | `s3://fcp-indi/data/Projects/FCON1000/` | AWS CLI 批量同步 | 2,901 · 59.44 GB |
| Narratives | `s3://openneuro.org/ds002345/` | AWS CLI 批量同步 | 4,194 · 144.44 GB |
| SWU SLIM | `s3://fcp-indi/data/Projects/INDI/SLIM/` | aria2 分段，最多 2 包同时传输，每包最多 4 个连接 | 46 · 124.44 GB |
| BOLD5000 | `s3://openneuro.org/ds001499/` | AWS CLI 批量同步 | 6,649 · 83.99 GB |
| MPI Mind-Brain-Body / LEMON MRI | `s3://openneuro.org/ds000221/` | AWS CLI 批量同步 | 14,715 · 419.27 GB |

本批选定范围共 28,505 个文件、831.58 GB。列出的数量和体量来自执行时清单，未来可随源端发布变化。范围主要是原始影像与配套元数据，SLIM 选原始压缩包和三个表型 TSV，MPI 只计算一份 MRI。涉及审批的数据由使用者另行处理。

历史上试过 curl 与 HTTP Range 的多连接测速。一次短测中，2、8、16 路在同一路径的观测速度分别为 1.32、2.59、4.30 MB/s，测试内容未写入目标盘。正式批量下载的 AWS CLI 使用 8 路请求，SWU SLIM 使用独立的 aria2 策略。公开版用内置 HTTP 下载器覆盖原 curl 路线，并用实际样本和写盘时间帮助其他电脑选择参数。

本项目沿用数据源清单、并发短测、已完成文件判定、单文件与分段恢复、源端校验及本地 SHA-256。使用 `Ctrl+C` 暂停后，应等命令退出再移除硬盘。不同系统自行选择保存位置。工具记录通用的文件完整性，影像专业质量控制可以在下载后按数据集需求另外运行。
